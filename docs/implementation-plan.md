- منهج مستويات 0–10 بدروس عربية حقيقية (ليست عناوين فارغة)
- تمارين، اختبارات، مشاريع، قاموس، بحث
- تقدم محلي وقفل مستويات
- صفحات تمارين مجمّعة، إعدادات، 404
