# هيكل الصفحات

## الرئيسية

شريط لاصق، بطل بوصف وزر بدء/استكمال، شبكة مستويات، مهارات، مشاريع، أسئلة.

## الخريطة

خط زمني عمودي لكل مستوى: حالة قفل، شريط إنجاز، قائمة دروس، رابط المستوى.

## الدرس

عمود دروس المستوى، متن الشرح، كود مع نسخ، اختبار، ملاحظات، سابق/تالي.

## اللوحة

تقدم كلي، استكمال، مستويات، محفوظات، ملاحظات، نتائج، توصية الخطوة التالية.
