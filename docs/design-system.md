# نظام التصميم

- خط IBM Plex Sans Arabic للنصوص، IBM Plex Mono للكود
- اتجاه RTL افتراضي، الكود LTR
- ألوان: خلفية دافئة، براند ترابي `#c45c26`، أخضر ثانوي، أزرق للتأكيد
- وضع داكن عبر `data-theme` على `html`
- تركيز لوحة مفاتيح: outline 3px
- بطاقات بحدود خفيفة وظل خفيف، بدون ازدحام تدرجات
- احترم `prefers-reduced-motion`
