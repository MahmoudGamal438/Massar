# نموذج المحتوى

الكيانات في `src/app/core/models/content.models.ts`:

LearningPath → Level → Module → Lesson → LessonSection / CodeExample / Exercise / Quiz.

UserProgress في التخزين المحلي: دروس مكتملة، مفتوحة، تمارين، نتائج اختبار، علامات، ملاحظات، سلسلة أيام.

## قواعد الإكمال

- فتح الدرس ≠ إكمال
- إن وُجد تمرين يلزم تعليمه مكتملًا بعد إظهار الحل بوعي
- إن وُجد اختبار يلزم النجاح بنسبة النجاح المعرّفة

## التحقق

`ContentService.validateCatalog()` يفحص المعرّفات المكررة، الوحدات، الروابط الداخلية للتمارين والاختبارات والمتطلبات.
