# متطلبات المنتج

## المشكلة

المتعلم العربي يواجه محتوى Angular إما إنجليزيًا متقدمًا أو شروحات مبعثرة بلا تقدم حقيقي ولا مشاريع بمعايير قبول.

## المنتج

منصة تعلم (Learning Platform) اسمها الحالي «مسار أنجولار»، قابلة لتغيير الاسم دون ربط المكوّنات بالاسم.

## المستخدم

مبتدئ بلا خلفية، أو شخص يعرف HTML ويريد مسارًا حتى Angular وسوق العمل.

## نطاق النسخة الحالية

- تطبيق Angular 19 يعمل
- أحد عشر مستوى (0–10) بدروس عربية
- تمارين باختبارات تلميح ثم حل
- اختبارات تُصحَّح في المتصفح
- تقدم محلي، علامات، ملاحظات، بحث، قاموس، مشاريع
- RTL ووضع داكن

## خارج النطاق الحالي (موثّق)

- حسابات ومزامنة أجهزة
- Backend وصلاحيات خادم
- محرر أكواد وSandbox لتشغيل كود المستخدم
- لوحة إدارة محتوى للمحررين

## نجاح

تشغيل، تنقل، دروس غير فارغة، تقدم لا يُحتسب بالفتح وحده، وتوثيق صادق للتنازلات.
