# الاختبار

## ما يُشغَّل

- `npx ng build` تحقق ترجمة وحزم
- اختبارات وحدة Karma عند توافر Chrome:
  - فريدية المعرّفات وصحة الكتالوج
  - البحث
  - الفتح لا يُكمل الدرس
  - قفل المستوى 1 قبل العتبة

## يدوي للمسار الرئيسي

1. فتح الرئيسية والاتجاه RTL
2. بدء أول درس
3. حل اختبار وتمرين ثم إكمال
4. علامة وملاحظة تظهر في اللوحة
5. بحث كلمة
6. تبديل الثيم وإعادة التحميل

## لم يُدعَ تشغيله هنا

E2E كامل وLighthouse بأرقام، لعدم تثبيت متصفح CI في كل الحالات.
