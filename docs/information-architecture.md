# معمارية المعلومات

## التدفق الرئيسي

الرئيسية → الخريطة → المستوى → الدرس → تمرين/اختبار → لوحة التقدم

## الصفحات

- `/` الرئيسية
- `/roadmap` الخريطة
- `/levels/:levelId` المستوى
- `/learn/:lessonId` الدرس
- `/exercises` فهرس التمارين
- `/exercises/:id` التمرين
- `/projects` المشاريع
- `/dashboard` اللوحة
- بحث الهيدر (بدون صفحة مستقلة)
- `/glossary` المصطلحات
- `/structure` هيكل المشروع
- `/ai` الذكاء الاصطناعي
- `/job` سوق العمل
- `/settings` الإعدادات
- غير المعروف → 404 داخل الهيكل

## مبادئ

- معرفات دروس مستقرة (`l5-http`)
- إضافة درس = بيانات لا صفحة يدوية
- القفل على المستوى السابق بنسبة إتقان معلنة
