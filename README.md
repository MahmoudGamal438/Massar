# مسار أنجولار

منصة تعليمية عربية (RTL) لتعلم تطوير الواجهات من الصفر حتى Angular والاستعداد لسوق العمل. إكمال المسار يساعد ولا يضمن التوظيف.

## التشغيل

Node.js 18 أو 20 أو 22.22.x (Angular 19. بيئة Node 22.22.0 لا تلبي حد Angular 22).

```bash
npm install
npm start
```

العنوان المحلي: `http://localhost:4200/`

```bash
npm run build
```

## ماذا تعمل النسخة الحالية

- أحد عشر مستوى بمحتوى عربي حقيقي
- دروس، تمارين بتلميحات، اختبارات تُصحَّح، مشاريع بمعايير قبول
- تقدم في المتصفح: الإكمال ليس مجرد فتح الدرس
- بحث في الهيدر، قاموس، لوحة، وضع داكن، إعدادات

التفاصيل في `docs/`.

## ما لم يُبنَ بعد

حسابات سحابية، Backend، محرر أكواد مع تشغيل آمن. لا تدّعي الواجهة تشغيل كودك على الخادم.
